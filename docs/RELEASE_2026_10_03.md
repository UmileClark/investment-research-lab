# Ten additional studies · 3 October 2026

This release expands the lab from nine to **nineteen** reproducible projects. New research is dated today; it is not presented as a tool or forecast used in 2024. It adds no paper trades. The latest archived holdings are dated **25 September 2026**, while the common-session return panels end **18 September 2026**. The pending IEF/SHY instruction still requires execution verification.

Every study includes a question, explicit method, results, invalidation conditions, source roles, Python module, executed notebook, CSV, JSON and chart. Source papers supply either a specific estimator or a motivation; reports explicitly distinguish those roles from full replications.

## Reproduction and validation

```bash
python -m unittest discover -s tests -v
python -m investment_lab all
python scripts/execute_notebooks.py stress currency factors trend volcontrol drawdowns varchecks crypto-budget option-hedges decision-log
```

33 local tests pass. Added controls cover price/FX compounding, scenario reconciliation, known regression and hedge identities, signals preceding fills, future-price invariance, cash/fee conservation, drawdown recovery, prior-only VaR, zero-exception coverage, covariance validity, put–call parity, collar bounds and decision-record chronology/tampering. GitHub Actions is a separate verification; consult its run for this release.

The sensitivity grids are fully reported; no best-performing parameter is silently selected. Hypothetical constant-weight baskets, executable-rule simulations and the reconstructed discretionary ledger are separate experiments. Most studies use a common weekday calendar: daily annualisation uses 252 and does not claim to measure crypto weekend risk fully.

## What to discuss in an interview

Choose two or three projects to defend deeply. Derive an identity, change an assumption, explain the change in output and name a limitation that would block implementation. Explain why a strategy that reduces drawdown can still be unattractive after fees and cash drag. Describe this work accurately as an AI-assisted, reproducible research lab; demonstrate ownership by modifying and interpreting the models yourself.

The strongest next improvement is new prospective evidence: source-linked operating forecasts for familiar companies, verified executable data and a record of forecasts, rejected alternatives and subsequent outcomes. More retrospective models alone cannot create an investment track record.
